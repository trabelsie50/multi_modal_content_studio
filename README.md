# Multi-Modal Content Studio 🎬

بوت تيليجرام متكامل يعمل كاستوديو محتوى آلي متعدد الوسائط، يستقبل مقالات أو أفكاراً من المستخدم وينتج فيديوهات جاهزة للنشر عبر سير عمل ذكي من عدة مراحل ذكاء اصطناعي.

---

## 📌 نظرة عامة على المشروع

يُعدّ **Multi-Modal Content Studio** بوت تيليجرام ذاتي التشغيل يقوم بتحويل المقالات الطويلة أو الأفكار النصية إلى محتوى فيديو جاهز للنشر على منصات مثل Reels و TikTok. يعمل البوت عبر سير عمل متعدد المراحل يعتمد على التنسيق بين عدة خدمات ذكاء اصطناعي:

1. **الاستقبال والتنقيح** — قراءة المقال واستخلاص سيناريو مقسّم إلى مشاهد قصيرة باستخدام Google Gemini API.
2. **توليد الصور** — إنشاء صور معبرة لكل مشهد باستخدام Google Imagen API (Vertex AI) مع تحسين الجودة.
3. **التوليد الصوتي** — تحويل السيناريو إلى تعليق صوتي احترافي باستخدام ElevenLabs API.
4. **المونتاج الآلي** — دمج الصور والصوت والمؤثرات الانتقالية لإنتاج فيديو عمودي (1080×1920) باستخدام MoviePy.
5. **التسليم** — إرسال الفيديو النهائي وملف السيناريو النصي إلى المستخدم عبر تيليجرام.

### ✅ المميزات الرئيسية

- **بنية Clean Architecture** مع برمجة غير متزامنة (Async/Await) بالكامل.
- **تنسيق متعدد الوسائط** (Multi-AI Orchestration) بين خدمات Gemini و Imagen و ElevenLabs.
- **إدارة آمنة للمفاتيح** عبر متغيرات البيئة (.env).
- **دعم الفيديو العمودي** بحجم 1080×1920 المناسب لمنصات التواصل الاجتماعي.
- **مؤثرات انتقالية** (Transitions) وخلفية موسيقية اختيارية أثناء المونتاج.
- **ترجمة تلقائية للنصوص** مع إمكانية إضافة ترجمة مدمجة على الفيديو.

## 🛠️ المتطلبات المسبقة

- **Python** 3.10 أو أحدث
- **pip** (مُدير حزم بايثون)
- حساب على **Google Cloud** مع تفعيل Vertex AI API ومفتاح API لمزود Imagen
- حساب على **ElevenLabs** للحصول على مفتاح API
- **Google Gemini API Key** من [Google AI Studio](https://aistudio.google.com/)
- ملف **Google Application Credentials** (JSON) للوصول إلى Vertex AI (اختياري لمسار Imagen)

## 📦 التثبيت

### 1. استنساخ المستودع

```bash
git clone https://github.com/your-username/multi_modal_content_studio.git
cd multi_modal_content_studio
```

### 2. إنشاء بيئة افتراضية

```bash
python -m venv venv

# على Linux/macOS:
source venv/bin/activate

# على Windows:
venv\Scripts\activate
```

### 3. تثبيت الحزم المطلوبة

```bash
pip install -r requirements.txt
```

### 4. قائمة الحزم الأساسية

| الحزمة | الغرض |
|---|---|
| `python-telegram-bot` | إنشاء بوت تيليجرام (الإصدار v20+، غير متزامن) |

| `beautifulsoup4` | تنقيح HTML لاستخراج النصوص |

## ⚙️ إعداد متغيرات البيئة

أنشئ ملف `.env` في الدليل الجذري للمشروع وأضف المتغيرات التالية:

```env
# === توكن بوت تيليجرام ===
TELEGRAM_BOT_TOKEN=1234567890:ABCDefghIJKLmnopQRSTuvwxYZ

# === Google Gemini API ===
GEMINI_API_KEY=your_gemini_api_key_here

# === ElevenLabs API (التوليد الصوتي) ===
ELEVENLABS_API_KEY=your_elevenlabs_api_key_here

# === Google Cloud (Vertex AI - Imagen) ===
GOOGLE_APPLICATION_CREDENTIALS=path/to/your/service-account.json
IMAGEN_API_KEY=your_imagen_api_key_here

# === المسارات ===
OUTPUT_DIR=output
SCENES_DIR=output/scenes
FINAL_VIDEO_DIR=output/final_videos
```

> ⚠️ **تنبيه:** لا تشارك ملف `.env` أبدًا. أضفه إلى `.gitignore` قبل رفع المشروع إلى أي مستودع.


## 🏗️ بنية المشروع وشرح الملفات

### `config.py` — طبقة الإعدادات

يقرأ جميع المفاتيح السرية والمسارات من ملف `.env` عبر `python-dotenv` ويوفر كائن `Settings` موحّد يُستخدم في كل أجزاء المشروع. يتضمن المتغيرات التالية:

- `TELEGRAM_BOT_TOKEN`, `GEMINI_API_KEY`, `TTS_API_KEY`, `ELEVENLABS_API_KEY`
- `GOOGLE_APPLICATION_CREDENTIALS`, `IMAGEN_API_KEY`
- `OUTPUT_DIR`, `SCENES_DIR`, `FINAL_VIDEO_DIR`

### `models.py` — نماذج البيانات المشتركة

يُعرّف جميع `dataclasses` التي تُشكّل اللغة المشتركة بين جميع المراحل:

- `ArticleInput` — المدخلات (رابط مقال أو نص خام)
- `Scene` — مشهد واحد (وصف بصري، نص المشهد)
- `Script` — السيناريو الكامل (قائمة المشاهد + وصف عام)
- `ImageResult` — نتيجة توليد صورة (مسار الملف، البرومبت، المشهد)
- `VoiceoverResult` — نتيجة التوليد الصوتي (مسار الملف الصوتي، المدة)
- `VideoResult` — نتيجة الفيديو النهائي (مسار الفيديو، المدة، الأبعاد)
- `PipelineResult` — نتيجة سير العمل الكامل (جميع المراحل مجتمعة)

### `gemini_service.py` — خدمة Gemini

تستقبل رابط مقال أو نصاً خاماً، تقرأ محتواه عبر نموذج Gemini متعدد الوسائط، وتستخرج سيناريو مقسّماً إلى مشاهد قصيرة مع وصف بصري لكل مشهد. تتضمن دوالاً للتعامل مع HTML، تحليل الاستجابات، وإنشاء سيناريو بديل عند الحاجة.

### `image_service.py` — خدمة الصور

تستخدم Google Imagen API عبر Vertex AI لتوليد صور معبرة من أوصاف المشاهد، مع دالة تحسين الجودة (upscale) لضمان دقة عالية مناسبة للفيديو العمودي (1080×1920).

### `tts_service.py` — خدمة الصوت

تستخدم ElevenLabs API لتوليد تعليق صوتي احترافي من نص السيناريو المستخرج، مع دعم لاختيار الصوت ونبرة الصوت (Stability / Similarity Boost). تُنتج ملفاً صوتياً بصيغة MP3.

### `video_service.py` — خدمة الفيديو

تستخدم MoviePy لدمج الصور المولدة مع التعليق الصوتي وخلفية موسيقية اختيارية ومؤثرات انتقالية لإنتاج فيديو عمودي (1080×1920) متناسق مناسب لـ Reels و TikTok.

### `orchestrator.py` — المنسق الرئيسي

يربط جميع المراحل ببعضها في سير عمل متناسق: يستقبل المدخلات، يستدعي Gemini للاستخلاص، يولّد الصور لكل مشهد، يُنشئ التعليق الصوتي، يُركّب الفيديو النهائي، ويعيد النتيجة الكاملة. يتبع نمط `async/await` بالكامل.

### `bot.py` — نقطة الدخول

يُنشئ تطبيق `python-telegram-bot` غير متزامن، يُعرّف معالجات الرسائل (أمر `/start`، رسائل نصية تحتوي على روابط أو نصوص)، ويستدعي `Orchestrator` لمعالجة كل طلب وإرسال النتائج للمستخدم.
